Image Dataset Explorer
Folders

Open an image dataset

Pick the root folder of any dataset — or drag it anywhere onto this window. Every subfolder is scanned and sampled. Nothing is uploaded: files are read locally by your browser and never leave this machine.

  • 4 or 5 random images are shown from each folder that contains images.
  • If the whole dataset holds fewer than 100 images, every image is shown.
  • Switch to All images at any time, or expand a single folder in place.
  • Supported: jpg, jpeg, png, gif, webp, bmp, tif, tiff, avif, svg.
